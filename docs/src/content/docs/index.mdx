## Why

Every YouTube Music client is either a browser tab or an Electron app. ytkew
is neither: it is a terminal program that hands playback to **mpv**, so a slow
redraw can never stutter the audio, and it looks and behaves like
[kew](https://github.com/ravachol/kew), which got the interface right.

<CardGrid>
  <Card title="Full-resolution cover art" icon="star">
    Kitty graphics where the terminal supports it, sixel where it does not,

  </Card>
  <Card title="Gapless playback" icon="right-arrow">
    The next track is resolved and buffered while the current one plays, so
    transitions never stall on a yt-dlp round trip.
  </Card>
  <Card title="Spectrum visualizer" icon="bars">

  </Card>
  <Card title="Colours from the artwork" icon="sun">
    The palette is sampled from the album cover — or pick one of ten themes,
    or write your own.
  </Card>
  <Card title="vim keys" icon="setting">
    An optional preset with `gg`, `G`, `ctrl+d`, `dd` and the rest.
  </Card>
  <Card title="MPRIS" icon="laptop">
    Media keys work, and it appears in the GNOME or KDE now-playing panel
    with artwork and a seek bar.
  </Card>
</CardGrid>

## Get going

```sh
git clone https://github.com/dtDhruv/ytkew
cd ytkew
make install
ytkew radiohead creep
```

Needs `mpv` and `yt-dlp` on `PATH`. Search, radio and lyrics work signed out;
only your own library needs [credentials](/ytkew/start/signing-in/).
