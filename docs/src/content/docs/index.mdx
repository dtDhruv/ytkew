## Why

Every YouTube Music client is either a browser tab or an Electron app. ytkew
is neither: it is a terminal program that hands playback to **mpv**, so a slow
redraw can never stutter the audio, and it looks and behaves like
[kew](https://github.com/ravachol/kew), which got the interface right.

## Get going

```sh
git clone https://github.com/dtDhruv/ytkew
cd ytkew
make install
ytkew radiohead creep
```

Needs `mpv` and `yt-dlp` on `PATH`. Search, radio and lyrics work signed out;
only your own library needs [credentials](/ytkew/start/signing-in/).
